# Redstone Quill | [![][cf-shield]][cf-link] [![][mr-shield]][mr-link]

Redstone Quill is a fork of the abandoned [Redstone Pen](https://legacy.curseforge.com/minecraft/mc-mods/redstone-pen), only adding the quill item. More features and integrations are planned; it currently has Jade integration, showing the power level of the Redstone Tracks.
